## 📖 About

This repository contains the programs and practice work I wrote to Understand the core fundamentals of Languages.

The goal: Build strong programming fundamentals and problem-solving skills for placements.

## 📂 Repository Structure

```
Pre_Placement_Activity/
│
├── C Programming/       → C fundamentals
├── C++ Programming/     → OOP concepts in C++
├── Java Programming/    → Core Java and OOP
└── README.md
```

## 🧠 Topics Covered

### 🔹 C Programming
- Core C fundamentals and logic building
- Programs from the training sessions

### 🔹 C++ Programming
- Classes and objects
- Access specifiers (private, public, protected)
- Virtual functions and polymorphism

### 🔹 Java Programming
- Sequence, selection and iteration
- OOP concepts and single-level inheritance
- Interfaces
- Multithreading (ThreadDemo series)

## ▶️ How to Run

**C**
```bash
gcc filename.c -o output
./output
```

**C++**
```bash
g++ filename.cpp -o output
./output
```

**Java**
```bash
javac FileName.java
java FileName
```

On Windows, run `output` instead of `./output`.
